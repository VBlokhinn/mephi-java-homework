# Сервис коротких ссылок (URL Shortener)

Консольное Java-приложение для создания и управления короткими ссылками.

### Возможности сервиса
- Сокращение URL с гарантией уникальности ссылки для каждого пользователя.
- Открытие исходной ссылки в браузере прямо из консоли.
- Управление временем жизни (TTL) и автоматическое удаление просроченных ссылок.
- Ограничение количества переходов и блокировка ссылки при исчерпании лимита.
- Разделение доступа по UUID: редактировать и удалять ссылку может только владелец.
- Уведомления об исчерпании лимита и истечении срока жизни ссылки.
- Загрузка настроек из файла конфигурации (config.properties).

## Запуск приложения
```bash
./gradlew :url-shortener:run --console=plain -q
```

## Команды консоли
| Команда | Описание | Пример |
|---|---|---|
| `shorten <URL> [лимит] [TTL]` | Создать короткую ссылку (лимит и TTL в секундах) | `shorten https://ya.ru 5 3600` |
| `open <код_или_ссылка>` | Открыть ссылку в браузере | `open clck.ru/Ab3X9z` или `open Ab3X9z` |
| `list` | Список всех ссылок текущего пользователя | `list` |
| `info <код_или_ссылка>` | Подробная информация о ссылке | `info Ab3X9z` |
| `edit <код_или_ссылка> <лимит>` | Изменить лимит переходов (только владелец) | `edit Ab3X9z 10` |
| `delete <код_или_ссылка>` | Удалить ссылку (только владелец) | `delete Ab3X9z` |
| `user current` | Показать UUID текущего пользователя | `user current` |
| `user new` | Создать нового пользователя и переключиться | `user new` |
| `user switch <UUID>` | Войти под другим UUID | `user switch 7a5e881b-...` |
| `help` | Показать список команд | `help` |
| `exit` | Завершить работу | `exit` |

## Настройки (src/main/resources/config.properties)
```properties
default.ttl.seconds=86400
default.click.limit=5
short.url.domain=clck.ru/
cleanup.interval.seconds=5
```

## Тестирование
В проекте реализовано 18 unit- и интеграционных тестов (проверка уникальности ссылок, лимитов, TTL, контроля доступа по UUID и работы с конфигом).

Запуск тестов:
```bash
./gradlew :url-shortener:test
```
