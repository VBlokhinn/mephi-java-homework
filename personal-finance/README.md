# Система управления личными финансами

Консольное Java-приложение для учета доходов, расходов, управления бюджетами по категориям и финансового анализа.

Разработано в рамках сессионного итогового задания по курсу Принципы объектно-ориентированного программирования.

### Возможности сервиса
- Авторизация пользователей по логину и паролю (SHA-256), поддержка нескольких независимых пользователей.
- Учет доходов и расходов с привязкой к категориям, датам и описаниям.
- Управление бюджетами: установка лимитов расходов по категориям, контроль остатка бюджета.
- Оповещения: предупреждение при достижении 80% бюджета категории, при перерасходе (100%+), а также при нулевом или отрицательном балансе.
- Статистика и аналитика: сводный отчет по доходам, расходам, общему балансу и таблица по категориям.
- Фильтрация: выборка операций за указанный период дат и по выбранным категориям.
- Экспорт и импорт: сохранение истории операций в CSV-файл и обратная загрузка.
- Автоматическое сохранение данных кошелька в JSON-файлы при выходе и загрузка при авторизации.

## Запуск приложения
```bash
./gradlew :personal-finance:run --console=plain -q
```

## Команды консоли
| Команда | Описание | Пример |
|---|---|---|
| `register <логин> <пароль>` | Регистрация нового пользователя | `register alex pass123` |
| `login <логин> <пароль>` | Вход в систему | `login alex pass123` |
| `income <сумма> <кат> [описание]` | Добавить доход | `income 50000 Зарплата Аванс` |
| `expense <сумма> <кат> [описание]` | Добавить расход | `expense 1500 Еда Обед в кафе` |
| `budget set <категория> <лимит>` | Установить лимит бюджета для категории | `budget set Еда 15000` |
| `budget remove <категория>` | Удалить бюджет категории | `budget remove Еда` |
| `stats` | Финансовая сводка и статистика по категориям | `stats` |
| `history [от] [до] [категория]` | История операций с фильтром по датам и категории | `history 2026-01-01 2026-12-31 Еда` |
| `export <файл.csv>` | Экспорт операций в CSV | `export report.csv` |
| `import <файл.csv>` | Импорт операций из CSV | `import report.csv` |
| `logout` | Выйти из текущего аккаунта | `logout` |
| `help` | Показать список доступных команд | `help` |
| `exit` | Сохранить данные и выйти из программы | `exit` |

## Тестирование
В модуле реализовано 18 unit- и интеграционных тестов:
- Регистрация и авторизация (`AuthServiceTest`, 4 теста).
- Доходы, расходы, бюджеты, алерты 80% и 100%, фильтры (`FinanceServiceTest`, 7 тестов).
- Экспорт и импорт CSV (`CsvExportImportServiceTest`, 3 теста).
- Сохранение и загрузка JSON (`FileWalletRepositoryTest`, 2 теста).
- Интеграционные сценарии и изоляция данных (`FinanceIntegrationTest`, 2 теста).

Запуск тестов:
```bash
./gradlew :personal-finance:test
```
