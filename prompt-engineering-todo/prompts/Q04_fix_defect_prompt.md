# Запрос Q04: Устранение дефекта D01 (Условный шаг E)
Версия: 1.0
Чат: Основной рабочий чат Gemini
Статус: Условный шаг (отправлен при обнаружении сбоя D01)

## Текст отправленного промпта:

При тестировании граничных условий обнаружен дефект (D01).

Цель:
Исправить локальную ошибку валидации граничного индекса задачи, не изменяя остальную структуру программы.

Входные данные и симптом сбоя:
При проверке сценария завершения последней задачи в списке:
Вход:
add Первая задача
done 1
exit

Ожидаемый вывод:
ADDED 1
DONE 1
BYE

Фактический вывод:
ADDED 1
ERROR: NOT_FOUND
BYE

Затронутый метод:
private static Integer parseIndex(String line, int cmdLength, int size) {
    String arg = line.length() > cmdLength ? line.substring(cmdLength).trim() : "";
    if (arg.isEmpty()) {
        System.out.println("ERROR: INVALID_ID");
        return null;
    }
    int id;
    try {
        id = Integer.parseInt(arg);
    } catch (NumberFormatException e) {
        System.out.println("ERROR: INVALID_ID");
        return null;
    }
    if (id < 1 || id >= size) {
        System.out.println("ERROR: NOT_FOUND");
        return null;
    }
    return id - 1;
}

Действие:
Локализуй ошибку в условии проверки границы id и предоставь исправленный метод parseIndex.

Ограничения:
1. Исправление должно быть строго локальным (не переписывай всю программу заново).
2. Соблюдай требования R05 и R07: допустимы индексы от 1 до size включительно.
3. Код метода должен укладываться в общий лимит строк.

Формат ответа:
1. Краткое объяснение причины сбоя.
2. Исправленный код метода parseIndex.

Критерий успешности:
Условие корректно принимает id, равный size, и отклоняет id < 1 и id > size.

Действия при неопределенности:
Если сомневаешься в границах, строго ориентируйся на требование: список содержит задачи от 1 до N, поэтому id = N является допустимым.
