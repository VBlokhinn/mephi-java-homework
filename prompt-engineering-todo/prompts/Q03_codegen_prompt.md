# Запрос Q03: Генерация исходного кода TodoListApp.java
Версия: 1.0
Чат: Основной рабочий чат Gemini

## Текст отправленного промпта:

Отлично! Тестовые сценарии T01–T12 и матрица покрытия утверждены. 
Отвечаю на твой вопрос: строки, состоящие только из пробелов или табуляций, считаются пустыми строками и молча игнорируются (как при line.trim().isEmpty()).

Теперь переходим к шагу C: написанию исходного кода программы.

Цель:
Написать полный, готовый к компиляции и запуску исходный код консольного приложения TodoListApp.java, полностью проходящий все сценарии T01–T12.

Входные данные:
1. Требования к программе v1.1 (R01–R10).
2. Утвержденные тестовые сценарии T01–T12.
3. Уточнение: пустые строки и строки только из пробелов молча игнорируются.

Действие:
Реализуй программу на Java 17 в одном классе. Обеспечь чтение команд из стандартного ввода (System.in), хранение задач в памяти, аккуратный парсинг аргументов и точный вывод сообщений строго по спецификации.

Ограничения:
1. Имя файла: TodoListApp.java.
2. Никаких объявлений package (код должен компилироваться в корне).
3. Использовать только стандартную библиотеку Java 17 (java.util.*, java.io.*).
4. Общий объем кода должен строго укладываться в диапазон от 50 до 150 строк (без учета пустых строк и однострочных комментариев). Пиши компактно и лаконично, избегай избыточных оберток, но не сжимай несколько операторов в одну строку.
5. Кодировка UTF-8.

Формат ответа:
1. Полный монолитный исходный код файла TodoListApp.java в одном блоке кода.
2. Точные консольные команды для компиляции и запуска через javac и java.

Критерий успешности:
Код компилируется компилятором Java 17 без ошибок, не содержит объявления package, содержит от 50 до 150 содержательных строк и проходит сценарии T01–T12.

Действия при неопределенности:
Если для соблюдения лимита 50–150 строк требуется упростить внутреннюю структуру классов (например, сделать Task статическим вложенным классом или хранить поля прямо), выбирай наиболее прямолинейное и компактное решение.
