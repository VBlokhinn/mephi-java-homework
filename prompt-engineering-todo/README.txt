ПРОЕКТ: Консольное приложение «Список дел в памяти» (TodoListApp)
Дисциплина: Промпт-инжиниринг для разработчиков (PJ)
========================================================================

1. НАЗНАЧЕНИЕ ПРОГРАММЫ
Программа предназначена для управления списком задач в оперативной памяти в рамках одной сессии.
Поддерживаются команды: add, list, done, remove, exit, а также обработка EOF.

2. СРЕДА ВЫПОЛНЕНИЯ
- Язык: Java 17.
- Зависимости: только стандартная библиотека Java.
- Кодировка: UTF-8.
- Пакет: отсутствует (дефолтный package).
- Объем исходного кода: 106 строк.

3. КОМАНДЫ СБОРКИ И ЗАПУСКА
Компиляция:
  javac --release 17 -encoding UTF-8 TodoListApp.java

Интерактивный запуск:
  java -Dfile.encoding=UTF-8 TodoListApp

Пакетный запуск сценария из файла:
  java -Dfile.encoding=UTF-8 TodoListApp < ../tests/inputs/T01.txt

4. РАСПОЛОЖЕНИЕ МАТЕРИАЛОВ:
- src/ — исходный код TodoListApp.java (106 строк)
- tests/ — сценарии тестирования и входные данные
- prompts/ — тексты отправленных запросов и ответов модели
- evidence/ — терминальные логи компиляции и запусков тестов
- docs/ — требования, карта процесса и журнал
