# Карточка сбоя D01

- **Дефект** D01; намеренно созданный учебный сбой.
- **Доказательство:** При попытке завершить или удалить последнюю задачу в списке ($id = N$) программа ошибочно возвращает `ERROR: NOT_FOUND` вместо `DONE <N>` / `REMOVED <N>`. Доказательство сохранено в `evidence/defect_D01_before.log`.
- **Область влияния:** Требования R05, R07; класс `TodoListApp.java`, метод `parseIndex`. Затронуты все операции `done` и `remove`, обращающиеся к граничному элементу.
- **Шаг возврата:** Возврат к реализации метода проверки индекса (Шаг E [Условный]).
- **Попытка 1:** Запрос `prompts/Q04_fix_defect_prompt.md`. Модель выявила нестрогое неравенство `id >= size` и заменила его на строгое `id > size`. Результат проверки: успешно пройден (`evidence/defect_D01_after.log`), полный регресс `T01`–`T12` также успешен.
- **Попытка 2:** Не потребовалась (дефект устранен с первой попытки).
- **Решение человека:** Исправление признано корректным. Дефект D01 исправлен и закрыт.
